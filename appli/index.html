      Classes

        Supprimer une classe efface aussi ses notes (deux appuis).

        Fichiers

        Efface les évaluations et les notes. Garde les classes, les élèves et les prénoms appris.

        Ce qu'on peut dire

        • Classe : « classe cinquième quatre »
        • Évaluation : « nouvelle évaluation », « évaluation deux », « dernière évaluation », « liste des évaluations »
        • Notes : « Emma douze », « Maxime treize virgule vingt-cinq » ou « treize et quart », « quinze et demi », « seize trois quarts », « Zoé a quatorze » (initiale), « absent », « non rendu », « non noté »
        • Élève touché : touche un nom (cadre bleu), puis dis seulement la note (« douze et demi »). L'appli répète « prénom, note ». Retoucher le nom annule.
        • Corrections : « annule » (dernière note), « remplace » (après « a déjà… »)
        • Autres : « manquants », « pause » puis « reprends », « exporter »
